# SignFlow - ヘッドレス認証フレームワーク

## 概要

SignFlowは、UIコンポーネントを持たない完全なサインイン・サインアップフロー管理システムを提供するヘッドレス認証フレームワークです。開発者がユーザーインターフェースデザインを完全にコントロールしながら、認証フローを実装できます。

## コンセプト

### ヘッドレスアーキテクチャ
- **UI非依存**: 事前定義されたUIコンポーネントを持たない
- **ロジック重視**: 認証状態管理とフロー制御を提供
- **開発者フレンドリー**: 任意のReact UIライブラリと簡単に統合

### 主要機能

#### 1. 認証フロー管理
- **サインインフロー**: メール/パスワード、ソーシャルプロバイダー
- **サインアップフロー**: メール認証付き登録
- **パスワードリセットフロー**: パスワード忘れと復旧
- **多要素認証**: SMS、TOTP対応
- **セッション管理**: トークンリフレッシュと検証

#### 2. プロバイダーサポート
- **AWS Cognito**: 主要ターゲット（既存のusermgrライブラリと互換）
- **拡張可能**: 追加プロバイダー用のプラグインアーキテクチャ

#### 3. 状態管理
- **React hooks**: useSignFlow、useAuthState、useSignIn、useSignUp
- **型安全**: 完全なTypeScriptサポート
- **リアクティブ**: リアルタイム状態更新

#### 4. フロー制御
- **ステップバイステップ**: ガイド付き認証プロセス
- **条件付きフロー**: ユーザー状態と設定に基づく
- **エラーハンドリング**: 包括的なエラー管理
- **バリデーション**: 組み込みフォーム検証

## 使用例

```typescript
import { SignFlowProvider, useSignIn } from '@infodb/signflow';

function SignInComponent() {
  const { signIn, state, error, isLoading } = useSignIn();
  
  const handleSubmit = async (email: string, password: string) => {
    await signIn({ email, password });
  };
  
  if (state === 'authenticated') {
    return <div>ようこそ！</div>;
  }
  
  return (
    <form onSubmit={handleSubmit}>
      {/* カスタムUIをここに配置 */}
    </form>
  );
}

function App() {
  return (
    <SignFlowProvider config={{ provider: 'cognito', region: 'us-east-1' }}>
      <SignInComponent />
    </SignFlowProvider>
  );
}
```

## アーキテクチャ

### コアコンポーネント

#### 1. SignFlowProvider
- 認証状態のコンテキストプロバイダー
- 設定管理
- プロバイダー初期化

#### 2. Hooks
- `useSignIn()`: サインインフロー管理
- `useSignUp()`: 登録フロー管理
- `usePasswordReset()`: パスワード復旧フロー
- `useAuthState()`: 現在の認証状態
- `useMFA()`: 多要素認証

#### 3. フローエンジン
- 認証フロー用のステートマシン
- ステップ遷移とバリデーション
- エラーハンドリングと復旧

#### 4. プロバイダーインターフェース
- 抽象認証プロバイダー
- Cognito実装
- 拡張性のためのプラグインシステム

### データフロー

```
ユーザーアクション → Hook → フローエンジン → プロバイダー → バックエンド
        ↓                    ↓
UIコンポーネント ← 状態更新 ← レスポンス処理
```

## 既存コンポーネントとの統合

### usermgrとの互換性
- 既存のusermgrライブラリと設定を共有
- Cognitoプロバイダー実装を再利用
- 一貫した認証パターン

### UIライブラリ統合
- 任意のReact UIライブラリと動作
- 人気ライブラリ（Material-UI、Ant Designなど）の例
- カスタムコンポーネントパターン
